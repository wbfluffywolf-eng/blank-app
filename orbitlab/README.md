# OrbitLab — MEE 453 Problem 2

An interactive Streamlit dashboard for a 138-minute elliptical satellite orbit, multistage rocket sizing, and the first 33 seconds of launch drag.

## Deployment to Streamlit Community Cloud
1. Sign in to https://share.streamlit.io/ with GitHub.
2. Create a new Streamlit app from repository `wbfluffywolf-eng/blank-app`.
3. Choose branch `mee453-orbitlab`.
4. Enter main file path `orbitlab/streamlit_app.py`.
5. Deploy. Your hosted URL will end in `.streamlit.app`.

The app's fuel requirements depend on editable design assumptions; the orbital quantities follow Keplerian mechanics.
